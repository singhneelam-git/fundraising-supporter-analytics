Fundraising Supporter Analytics

An end-to-end data analytics project exploring donor behaviour, fundraising performance and data quality for a fictional nonprofit organisation.

The project uses Python, SQL and Power BI to clean, analyse and visualise fundraising and CRM data.

🎯 Project Goals

* Analyse donation and donor trends
* Understand donor acquisition and engagement
* Identify active and lapsed supporters
* Explore campaign performance
* Assess fundraising data quality
* Build an interactive Power BI dashboard

📁 Data

The project contains six related datasets:

* 6,500 donors
* 26,089 donations
* 35 campaigns
* 38,370 contact-history records
* 26,089 financial transactions
* 6,500 CRM donor records

🔍 Initial Findings

* Average donation: £49.77
* Median donation: £23.95
* One-off donations: 19,414
* Regular donations: 6,675
* Active donors: 4,550
* Lapsed donors: 1,901
* Online was the largest acquisition channel
* Card was the most frequently used payment method
* Financial validation found 0 net-amount mismatches

🛠️ Tools

Python – Data cleaning, validation and exploratory analysis
SQL – Querying and fundraising analysis
Power BI – Data modelling, DAX and dashboard development
